# Canonweave artifact root

Every `*.md` file here (except this README) is one traced artifact: YAML
frontmatter is its **recipe** (what it derives from and how), the body is its
content. `graph.json` is generated by `canonweave build` — never hand-edit it;
regenerate on conflict.

- `canonweave check` — suspect + coverage report
- `canonweave gate` — gate verdict for the default profile (`ready-to-build`)
- `canonweave gate --profile ready-to-ship` — the stricter shipping profile
- edit an upstream artifact, run `canonweave check` — its dependents go suspect
- `canonweave reconcile <id>` then `canonweave reconcile <id> --apply` — close the loop

The seed artifacts below are real minimal examples: replace their bodies with
your product's content; the derivation edges are already wired.
