# Traceweave artifact root

Every `*.md` file here (except this README) is one traced artifact: YAML
frontmatter is its **recipe** (what it derives from and how), the body is its
content. `graph.json` is generated by `traceweave build` — never hand-edit it;
regenerate on conflict.

- `traceweave check` — suspect + coverage report
- `traceweave gate` — gate verdict for the default profile (`ready-to-build`)
- `traceweave gate --profile ready-to-ship` — the stricter shipping profile
- edit an upstream artifact, run `traceweave check` — its dependents go suspect
- `traceweave reconcile <id>` then `traceweave reconcile <id> --apply` — close the loop

The seed artifacts below are real minimal examples: replace their bodies with
your product's content; the derivation edges are already wired.
